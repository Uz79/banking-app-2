# Menu sidebar nav

Desktop sidebar navigation rail.

## Variants

| Variant | Path | Description |
|---------|------|-------------|
| `regular-compressed` | `variants/regular-compressed/default.svg` | 80px icon rail |
| `regular-extended` | `variants/regular-extended/default.svg` | 256px rail with labels |

## States

- `default` — only state exported

## Notes

- Distinct from `menu-sidebar`, which covers individual nav items (selected / unselected).
- Variant slugs follow Type-Case: `regular-compressed`, `regular-extended`.
